## Вимоги до проекту

1. Весь код обов'язково має проходити перевірку якості за допомогою відповідних інструментів, таких як clang-format для форматування коду, clang-tidy для статичного аналізу C++ коду та clazy для статичного аналізу Qt-specific коду.
2. Проект реалізується як десктопний додаток з графічним інтерфейсом за допомогою бібліотеки Qt.
3. Додаток підтримує роботу з SMTP сервером для надсилання електронних листів як за допомогою звичайного TCP, так і зашифрованного.
4. Система збереження зашифрованих облікових даних користувача, що дозволяє уникнути необхідності вводити облікові дані при кожному запуску програми.
5. Механізм збереження списку переписок в файловій системі, що підтримує як прямі листи, так і відповіді.
6. Підтримка роботи з Google Application-specific паролями для автентифікації на поштових серверах.
7. Система обробки помилок з відповідними повідомленнями для користувача, а також система логування як у файл так і в stdout.
8. Інтерфейс для відображення списку листів.
9. Асинхронна система для обробки запитів до серверів без блокування інтерфейсу користувача.
10. Модуль тестування з використанням GoogleTest для перевірки основної логіки додатку.
11. Низькорівнева документацію для коду.

## Опис проекту

Цей проект спрямований на створення функціонального поштового клієнта для десктопних систем з підтримкою SMTP протоколу. Користувачі зможуть налаштовувати облікові записи, переглядати вхідні листи, надсилати нові листи та керувати своїми повідомленнями. Проект реалізовано на мові програмування C++ з використанням бібліотеки Qt для створення графічного інтерфейсу. Для роботи з мережею використовуються стандартні засоби C++ та Boost.
